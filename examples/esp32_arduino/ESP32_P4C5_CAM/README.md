# ESP32_P4C5_CAM Arduino Library

Arduino I2C master driver library for the **ESP32-P4C5-CAM** Offline Vision and Streaming Module.

## Installation
Copy this folder into `Arduino/libraries/ESP32_P4C5_CAM` or import via Arduino IDE's **Sketch -> Include Library -> Add .ZIP Library...**.
